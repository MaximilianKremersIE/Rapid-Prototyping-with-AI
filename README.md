# Rapid-Prototyping-with-AI

IE University, Rapid Prototyping with AI, Group Project I. International students moving to Madrid have to find housing in an unfamiliar city, in a foreign language, across fragmented platforms that each show only part of the market. The process is arduous and opaque, so most only secure a place days or weeks before classes and arrive still searching, or settled into something worse than they wanted. We are building an AI housing-discovery platform around one question: how might we make housing discovery simple and straightforward enough that international students secure a verified place matching their criteria before they arrive, so they start university already settled?
